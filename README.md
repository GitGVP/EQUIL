# EQUIL

EQUIL is an equilibrium code based on the geometrical inverse formulation: input profiles are prescribed as functions of a normalized flux coordinate (\hat r), and the code solves for the plasma diamagnetism and the flux-surface geometry. In the anisotropic case, the magnetic-field strength (B) is also solved for self-consistently.

## Reproducing the article figures

If you want to reproduce the figures from the paper

**G. Van Parys, J. P. Graves, A. Merle, C. Heiss, M. Bassanini, and T. Glauser,**
*Investigation of finite aspect ratio effects in axisymmetric magnetic equilibria with toroidal rotation and pressure anisotropy*,

please check out the tagged paper snapshot `paper-v1.0` and use the README in that snapshot. It contains the exact reproduction scripts and the instructions needed to run them.

## Development version

This branch is the main development branch of EQUIL. It may differ from the paper snapshot and is not guaranteed to reproduce the published figures.
